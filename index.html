ShortsClipper

A personal desktop tool for the GTAVI YouTube channel (@gtavilifegame).

What it does

ShortsClipper runs on the channel owner's own computer. It cuts short vertical highlight clips from gaming livestreams whose creators allow clipping, adds subtitles, and lets the owner review every clip. Clips the owner approves are uploaded to the owner's own YouTube channel through the YouTube Data API, with a credit and a link to the original stream in the description.

Who can use it

ShortsClipper is not a public service. It is used only by the owner of the GTAVI channel to manage uploads to that channel.

YouTube API Services

ShortsClipper uses YouTube API Services (YouTube Data API v3) to upload approved videos to the owner's channel. By using ShortsClipper you agree to the YouTube Terms of Service and acknowledge the Google Privacy Policy.

Google data

The app requests access only to upload videos and read basic information about the signed-in channel. See the Privacy Policy.
